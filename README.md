# YouTube Chess Search

Find Daniel Naroditsky videos that show a chess position, then jump to the matching moment.

## MVP plan

1. Process public channel videos into timestamped board positions.
2. Normalize and index positions, then provide a search API.
3. Let users enter a FEN or arrange a board and browse matching moments.

This repository currently contains the default Angular starter site; search features are planned.

## Run locally

```sh
npm ci
npm start
```
